## 💻 Project

### Responsive Personal Portfolio Website

A fully responsive personal portfolio website built using **HTML5** and **CSS3**. This project showcases personal information, skills, projects, contact details, and a downloadable resume while adapting seamlessly across desktop, tablet, and mobile devices.

---

## ✨ Features

- Responsive Navigation Bar
- Hero Section
- About Me Section
- Skills Section
- Projects Section
- Contact Section
- Download Resume Button
- Mobile Responsive Layout
- Smooth Scrolling
- Modern UI Design
