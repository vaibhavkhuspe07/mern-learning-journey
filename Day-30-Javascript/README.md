# 💻 Mini Project

## Student Marks Management System

A beginner-friendly JavaScript project that manages student names and marks using arrays.

### Features

- Store student names
- Store marks
- Display all students
- Access array elements
- Update array elements
- Count total students
- Add new students using `push()`
- Remove last student using `pop()`
- Remove first student using `shift()`
- Add student at beginning using `unshift()`
