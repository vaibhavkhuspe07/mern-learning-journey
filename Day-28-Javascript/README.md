# 💻 Mini Project

## Student Marks Analysis System

A beginner-friendly JavaScript project that analyzes student data using different types of loops.

### Features

- Display all students using **for Loop**
- Find failed students using **while Loop**
- Show attendance using **do...while Loop**
- Display classroom seating using **Nested Loops**
- Stop searching after finding the topper using **break**
- Skip absent students using **continue**
