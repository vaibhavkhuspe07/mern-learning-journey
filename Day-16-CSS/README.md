## 💻 Project

### Responsive Photo Gallery using CSS Grid

A modern and responsive photo gallery built using HTML5 and CSS3. The project demonstrates how CSS Grid can be used to create clean, responsive layouts with equal spacing and hover animations.

## ✨ Features

- Responsive Grid Layout
- 9 Image Gallery
- Smooth Hover Zoom Effect

By completing this project, I learned:

- How CSS Grid works.
- Creating responsive layouts using Grid.

- Applying the `fr` unit for flexible layouts.
- Creating equal spacing using the `gap` property.
- Building responsive image galleries.
- Adding hover animations using `transform` and `transition`.
- Making layouts responsive with Media Queries.
