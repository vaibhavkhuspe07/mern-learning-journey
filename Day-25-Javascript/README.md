# 💻 Mini Project

## Student Profile Generator

A simple JavaScript project that stores student information using variables and displays the details in the browser console.

### Information Stored

- Full Name
- Age
- Degree
- College
- CGPA
- City
- Graduate Status

The project also displays the **data type** of each variable using the `typeof` operator.
