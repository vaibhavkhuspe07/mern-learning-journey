# 📖 Concepts Used

## ✔ Function Declaration

Displays employee information.

## ✔ Parameters & Arguments

Calculates the annual salary by passing the monthly salary as an argument.

## ✔ Return Statement

Returns the employee bonus from the function.

## ✔ Function Expression

Displays department information using a function stored in a variable.

## ✔ Arrow Function

Calculates employee tax using modern ES6 arrow function syntax.
