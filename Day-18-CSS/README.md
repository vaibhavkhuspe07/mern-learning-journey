## 💻 Project

A modern landing page built using **HTML5** and **CSS3**, featuring smooth animations, hover effects, floating illustrations, and a responsive layout. This project demonstrates how CSS animations and transitions can make a website more interactive and visually appealing.

- Building responsive animated layouts using Media Queries.
