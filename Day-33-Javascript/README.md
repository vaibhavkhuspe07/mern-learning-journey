# 💻 Mini Project

A beginner-friendly JavaScript project that demonstrates modern ES6 features using employee data.

- Extract Skills using Array Destructuring
- Copy Arrays using Spread Operator
- Copy Objects using Spread Operator
- Merge Multiple Arrays
- Merge Multiple Objects
- Update Object Properties using Spread
