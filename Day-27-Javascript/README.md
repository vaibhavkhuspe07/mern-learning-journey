# 💻 Mini Project

## Student Management Decision System

A beginner-friendly JavaScript project that demonstrates how different conditional statements are used in real-world scenarios.

### Features

- Check Exam Eligibility
- Check Pass or Fail
- Assign Grade Based on Marks
- Check Scholarship Eligibility
- Display Department Head using `switch`
- Display Attendance Status using Ternary Operator

# 📖 Concepts Used

## ✔ if Statement
Used to check whether the student's attendance is sufficient for exam eligibility.

## ✔ if...else
Used to determine whether the student has passed or failed.

## ✔ else if
Used to assign grades based on marks.

## ✔ Nested if
Used to check scholarship eligibility based on marks and fee payment status.

## ✔ switch Statement
Used to display the Head of Department based on the student's department.

## ✔ Ternary Operator
Used to display the attendance status in a concise way.
